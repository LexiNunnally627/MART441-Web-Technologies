For my final project, I really wanted to revisit Phaser3. I really liked the workflow it provided and all the fun things we can do with it. I expanded upon my first game and made it a little bit more well rounded. While the first iteration was nice, it didn't feel complete and also felt messy. This game is more coheisive in theme, and there is more interactions avaiable to the player. 
I first started by changed the sprites and images used. I found the program had a cool graveyard background and a mummy sprite, so I used those. Then, instead of only having static platfoms I figured out how to make them move on the screen, which adds a little bit more difficulty.
Finally, I wanted to add a better lives system to the game. The original just had the player die if they hit one enemy; however, with this I found the way to give the player three chances. Along with that there is a randomized First Aid Kit that drops if the player needs another life. However, they can't always count on it dropping when they need it. 
I had so much fun creating this platformer type game, and I do see myself making more games with this format.
